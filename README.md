# KICKOFF 26

브라우저에서 즐기는 3D 축구 게임 (Next.js + three.js). 비상업 개인 팬 프로젝트예요.

- 저장소: https://github.com/cgim6939-droid/kickoff26 (Vercel에 연결돼 있어 `main`에 올리면 자동 배포)
- 축구 규칙 정리와 구현 현황: [docs/RULES.md](docs/RULES.md)

## 실행

```bash
npm install
npm run dev        # 개발 (http://localhost:3000)
npm run build && npm start   # 배포용 빌드 실행
```

주소 끝에 `?debug`를 붙이면 콘솔에서 `window.__soccer`로 경기 상태를 볼 수 있고, `?prof`는 프레임별 시간 측정(`window.__prof`)을 켜요.

## 게임 모드

| 모드 | 설명 |
|---|---|
| 플레이 › 킥오프 | 1P vs AI (난이도 6단계: 입문/아마추어/세미프로/프로/월드클래스/레전드) |
| 대회 › 컵 대회 | 8강 토너먼트 |
| 로컬 대전 | 한 키보드로 2명 |
| 관전 모드 | AI끼리 경기 |
| 온라인 › 방 만들기 / 코드로 참가 | 방 코드로 접속하는 온라인 1대1 (아래 참고) |

팀 선택 → **라인업**(포메이션·전술·선발/후보 교체, 11대11만) → 경기 설정(인원·시간·규칙·시간대·날씨·그래픽) 순서예요.

## 조작 (1P 기본)

| 키 | 동작 |
|---|---|
| ←↑↓→ | 이동 |
| S | 패스 / 수비 시 압박 (자동으로 가장 좋은 동료에게) |
| D (꾹) | 슛 — 게이지 62~90%에서 떼면 "굿 타이밍"(상단 구석, 정확도·파워 상승) |
| Z+D / X+D / V+D | 감아차기 / 칩슛 / 낮고 강한 슛 |
| W / A | 스루패스 / 로빙 패스·크로스 |
| E, Shift | 질주 |
| R | 개인기(헛다리) |
| Q | 선수 전환 |
| 1~6, B, 7/8, 9/0 | 경기 중 전술(스타일, 포메이션, 압박, 수비 라인) |
| C, M, Esc | 카메라, 소리, 일시정지 |

2P는 W A S D / F G R T / Shift, 오른쪽 사람은 방향키 / K L I O / J. 게임패드도 지원해요.

## 구조

```
app/                 Next.js 앱 (페이지, 전역 CSS)
components/SoccerGame.js   메뉴·팀 선택·라인업 편집·온라인 화면 (React)
lib/soccer/
  engine.js          경기 엔진 (60Hz 고정 간격, 렌더와 분리). 규칙, 물리, 세트피스
  ai.js              AI: 포메이션 슬롯, 공격/수비 계획, 패스·슛 판단, 키퍼 위치
  consts.js          경기장/물리 상수 (경기장 2400×1536)
  formations.js      포메이션·전술 프리셋, 선발 순서
  clubs.js           리그/클럽/국가대표/레전드 팀 데이터 (+ rosters.js, bench.js)
  rosters.js         2026-27 시즌 명단 (바뀐 선수만 덮어씀)
  looks.js           선수별 외모 (피부/머리/수염)
  scene3d.js         three.js 장면: 경기장, 선수(SkinnedMesh 1개/선수), 공, 카메라, 관중
  runtime.js         게임 루프, 입력, HUD, 리플레이, 온라인 방장/손님 처리
  net.js             PeerJS 기반 방 코드 접속
public/
  models/player.glb  선수 모델(뼈대 + 동작 + 머리/수염 변형)
  faces_real/        선수 얼굴 사진 (위키 사진을 얼굴 인식으로 잘라 160px)
  faces/             사진이 없는 선수용 Blender 3D 얼굴 렌더
  crests/            구단 엠블럼
blender/             모델·동작·얼굴 렌더 스크립트 (아래 참고)
```

## 멀티플레이 (온라인 1대1)

- 메뉴 → 멀티플레이 → **방 만들기**(팀 고르기 → 5자리 코드 표시) / **코드로 참가**.
- 방장의 브라우저가 경기를 계산하고 상태를 ~30Hz로 보냅니다. 손님은 키 입력만 보내고 받은 상태를 보간해서 그려요. 손님 화면은 자기 팀 기준으로 반대편에서 보여요(카메라·미니맵·방향키 반전).
- 연결 맺기에만 PeerJS 공용 서버를 쓰고, 이후에는 WebRTC로 직접 통신해요(제어용 신뢰 연결 + 상태용 비순서 연결). 손님 이동은 클라이언트 예측, 화면 오른쪽 위에 핑 표시. 네트워크에 따라 TURN 중계를 타면 지연이 커질 수 있어요.
- 온라인에서는 일시정지와 골 리플레이가 없어요.

## 모델 / 얼굴 만들기 (Blender 5.2)

```bash
bash blender/rebuild.sh <미리보기 폴더> views     # 몸·뼈대·동작 다시 만들고 public/models/player.glb 내보내기
bash blender/render_faces.sh                      # (blender/faces_input.json 기준) 3D 얼굴 렌더
```

- `build_player.py`(몸 + 뼈대 + 가중치), `animations.py`(동작: 달리기, 짧은 패스, 슛, 발리, 가슴 트래핑, 태클, 넘어짐, 헤딩, 세리머니/낙담, 숨 고르기, 키퍼 선방/던지기/펀트 등), `head.py`(머리/머리카락/수염)
- 자세한 내용은 [blender/README.md](blender/README.md)

## 데이터

- 팀 데이터는 `lib/soccer/clubs.js`, 2026-27 시즌 반영분은 `lib/soccer/rosters.js`예요. 선수 능력치(속도/슛)는 일부 추정값이에요.
- 선수 사진은 위키피디아/위키미디어에서 받은 것으로 **개인 비상업 용도**예요. 공개 저장소에 포함돼 있어 권리자가 요청하면 삭제될 수 있어요.
